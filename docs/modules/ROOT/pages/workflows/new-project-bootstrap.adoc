= Инициализация нового проекта
:navtitle: Новый проект

== Цель

Инициализировать новый репозиторий компонента из шаблона Cursor с минимальным расхождением.

Репозиторий компонента хранит собственные правила Cursor и AsciiDoc-документацию Antora.
Сборка сайта выполняется через центральный репозиторий с playbook.

== Шаги

1. Создайте пустой GitLab-проект;
2. Запустите `scripts/bootstrap.sh` или `scripts/bootstrap.ps1`, передав путь к целевому репозиторию;
3. Заполните `docs/antora.yml`: уникальный `name`, понятный `title`, подходящую `version`;
4. Заполните xref:architecture/overview.adoc[] под цели и границы нового проекта;
5. Проверьте `docs/modules/ROOT/nav.adoc`: удалите нерелевантные разделы и добавьте новые страницы;
6. Проверьте `globs` в локальных правилах `.cursor/rules/`;
7. Удалите нерелевантные примеры правил и компонентных страниц;
8. Зарегистрируйте репозиторий компонента в центральном `antora-playbook.yml` через `start_path: docs`;
9. Зафиксируйте первый коммит, который задаёт контекст проекта.

== Что копирует bootstrap

* `.cursor/rules/`;
* `docs/antora.yml`;
* `docs/modules/`;
* `README.adoc`;
* `.gitignore`, если он есть в шаблоне.
