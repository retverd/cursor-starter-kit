= Cursor Starter Kit
:navtitle: Обзор

Этот компонент описывает шаблон репозитория для запуска новых проектов в Cursor и публикации проектной документации через Antora.

Шаблон задаёт:

* базовые и локальные правила Cursor;
* Antora-структуру документации компонента;
* процессы инициализации нового репозитория компонента;
* соглашения по развитию правил и архитектурного контекста.

== С чего начать

Если вы создаёте новый репозиторий компонента, начните с xref:workflows/new-project-bootstrap.adoc[].

Если нужно подключить компонент к центральной сборке документации, используйте xref:workflows/antora-component-repo.adoc[].

Архитектурную модель шаблона описывает xref:architecture/rules.adoc[].
